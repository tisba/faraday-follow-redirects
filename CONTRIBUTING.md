# Contributing

> [!IMPORTANT]
> We do not accept GenAI/LLM contributions in any form. Please do not generate issues or comments to issues using GenAI in any form.[^1]

* This project is considered "complete" and generally does not accept new features.
* Pull Requests are restricted for this reason. Also because of "agentic" drive-by PRs.
* Bug reports are very welcome.
* Expect reasonably fast response times: **I'm committed to maintain this project.** Since it's done (see first point), don't take the low volume of changes as a sign of abandonment!

[^1]: You may use translation tools, if English is not your native language. But please, don't use GenAI to generate text for issues or comments. I'm not an native speaker myself and I absolutely don't mind if it's unpolished.
